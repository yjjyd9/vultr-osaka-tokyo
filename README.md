## 大阪和东京的差别，以及怎么自测

两个机房线路性质一样，差别在拥塞程度。东京是老节点，中国用户默认往那儿挤，NTT 线路在晚上 8 点到 11 点容易堵。大阪开得晚，用户少一些，同样的晚高峰会松一点，但好得有限，社区里的定位是“东京满了或者维护时的替代选项”。

自测要用对地址。Vultr 每个机房有独立的测试域名和 IP：

|  | 东京（NRT） | 大阪（KIX） |
| --- | --- | --- |
| Ping 域名 | `hnd-jp-ping.vultr.com` | `osk-jp-ping.vultr.com` |
| 测试 IPv4 | `108.61.201.151` | `64.176.34.94` |
| 测试 IPv6 | — | `2401:c080:3800:2075:5400:4ff:fe48:63c7` |
| 100MB 测速文件 | 同域名下 `vultr.com.100MB.bin` | 同域名下 `vultr.com.100MB.bin` |
| 1GB 测速文件 | 同域名下 `vultr.com.1000MB.bin` | 同域名下 `vultr.com.1000MB.bin` |

用法很简单：Windows 在 CMD 里敲 `ping osk-jp-ping.vultr.com`，Mac 和 Linux 在终端直接执行；测速文件把域名和文件名拼起来就能下载，浏览器打开 `osk-jp-ping.vultr.com` 还有一个在线测速页。白天那几个数字参考价值有限，晚上 20:00–23:00 再测一次，重点看丢包率。白天 50ms、晚上 200ms 还丢 15% 的线路，开了也白开。

这批测试地址是 2023 年大阪上线时记录的，域名形式和 Vultr 其他机房的命名规则一致，大概率还能用。万一不通，换成东京的地址对照测一次，就能判断是单个节点的问题还是你本地网络的问题。

## 联通、移动、电信，谁该开大阪

三家运营商的回国路径不一样，体验差得很远。

| 运营商 | 去程路径 | 参考延迟 | 结论 |
| --- | --- | --- | --- |
| 联通 | NTT → 联通 4837 | 100–130ms | 可以买，日本节点里算好的 |
| 移动 | CMI → PCCW 混合 | 120–150ms | 白天能用，晚高峰有波动，先测 |
| 电信 | NTT → Telia 绕美国 | 160ms 以上 | 不建议，晚高峰丢包明显 |

这些数字来自中文社区的测评汇总，不是官方承诺，各家测试时间、机型也不统一，只能当参考区间。真正要确认的是你自己的宽带，同一个城市不同小区都能测出不一样的结果。

“日本离得近，延迟肯定低”这句话在 Vultr 身上不成立。电信去程绕美国西海岸再回国，物理距离近没用，路由绕了半个地球，延迟比买洛杉矶还难看。有人在同样的预算下换美西机器，电信体验反而更稳。

电信用户如果非要用，可以装 BBR 或 BBR Plus 缓解丢包，或者套一层 Cloudflare。这俩都是缓解手段，治不了路由绕行。装完 BBR 之后社区反馈白天能跑 4K、联通晚高峰能维持 1080P，那是联通的数据，电信别抱同样期待。

## 月费 $5 是怎么算出来的

Vultr 按小时计费，普通套餐每月封顶 672 小时。这句话的意思是，一个月哪怕有 720 小时，也只按 672 小时收钱，超出部分不计费；你中途销毁实例，计费当场停。

按 $5/月这一档折算，小时价约 $0.0074。开 10 个小时不到一毛钱，开 50 个小时约 $0.37，开满整月就是 $5。$6 那档折算下来约 $0.0089/小时。这个算法是用月费除以 672 得来的，实际账单以控制台为准，量级不会差。

流量是另一笔账。每个账户每月有 2TB 免费出口流量，入站不计费，超出部分 $0.01/GB。2023 年 1 月起 Vultr 改成了账户级带宽池，额度不是月初一次性给满，而是按小时释放：2TB 除以 672，每小时大约放出 3GB。月初挂个下载站猛跑，很容易在额度还没释放出来的时候就触发超额计费。

## 常见问题

**大阪机房有 CN2 吗？**
没有。Vultr 是国际云厂商，日本两个机房都走标准 BGP，主力 NTT，不提供 CN2 GIA、CN2 GT 或软银线路。要 CN2 得找专门做中国优化线路的服务商。

**晚高峰慢怎么办？**
两个方向：装 BBR / BBR Plus 减少丢包影响，或者套 Cloudflare 牺牲直连速度换稳定性。换机房也是办法，东京堵的时候试试大阪，IP 段不同，路由可能略有差别。

**东京和大阪选哪个？**
先测。东京白天上海方向 40–60ms，联通体验通常最好；大阪用户少，晚高峰略松。测下来东京延迟低、丢包少就选东京，东京晚高峰丢包严重就开一台大阪对比一周。

**支持支付宝和微信吗？**
支持。Vultr 接受支付宝和微信充值，注册时填真实信息即可。

**能不能只开几个小时？**
能。按小时计费，随时销毁，销毁后不再计费。测试用途就按小时开，别直接买月付。
